> **Высокоскоростной асинхронный парсер каталога, цен со скидками СПП и складских остатков маркетплейса Wildberries.**  
> Спроектирован на чистом Python (Zero Dependencies) с прямым обращением к внутренним эндпоинтам мобильного API Wildberries. Обеспечивает мгновенный сбор тысяч товаров без затрат ресурсов на тяжёлые браузеры, детальный расчёт цен с учётом СПП (скидки постоянного покупателя / WB Кошелька) и автоматический экспорт в чистый Excel-ready CSV с кодировкой UTF-8 BOM.

## ✨ Ключевые особенности

* **Прямой API без браузеров (Zero Pip):** Никаких тяжёлых Chromium, Selenium или Playwright. Работает исключительно на стандартной библиотеке Python 3 со скоростью сотен запросов в секунду.
* **Честный расчёт цен СПП:** Автоматический пересчёт розничной цены, скидки продавца и финальной стоимости товара с учётом скидки WB Кошелька (СПП).
* **Складская аналитика:** Детализированная раскладка товарных остатков по ключевым региональным распределительным центрам (*Коледино, Казань, Электросталь, Санкт-Петербург, Краснодар, Екатеринбург*).
* **Excel-Ready экспорт:** Генерация CSV-файлов со специальным сигнатурным маркером `UTF-8 BOM (\ufeff)` и разделителями «точки с запятой». Таблицы открываются в Microsoft Excel на Windows/macOS с первого клика без кракозябр и сбитых столбцов.
* **Поддержка сетевых прокси:** Подключение пулов HTTP / SOCKS5 прокси для распределённого сбора сотен тысяч карточек без риска локальных сетевых ограничений.
* **Встроенный Demo-режим (`--demo`):** Автономная генерация реалистичного среза данных для мгновенной валидации структуры клиентом без подключения к внешней сети.

## 🚀 Быстрый старт

### 1. Сбор каталога по поисковому запросу:
```bash
python wb_scraper.py "кроссовки мужские" --pages 2 -o shoes.csv
```

### 2. Сбор карточки по конкретному артикулу (ID):
```bash
python wb_scraper.py -a 138536214 -o product_detail.json
```

### 3. Автономный демонстрационный запуск (без сети):
```bash
python wb_scraper.py "зимняя куртка" --demo -o winter_clothes.csv
```

### 4. Парсинг через прокси-сервер:
```bash
python wb_scraper.py "электроника" --proxy "http://user:password@185.22.15.4:8080"
```

## ⚙️ Справочник аргументов CLI

```text
usage: wb_scraper [-h] [-a ARTICLE] [-p PAGES] [-o OUTPUT] [--demo] [--proxy PROXY] [-v] [query]

Позиционные аргументы:
  query                 Поисковый запрос для сбора каталога (например, 'кроссовки').

Опции:
  -h, --help            Показать справку по аргументам и выйти.
  -a, --article ARTICLE Собрать данные по конкретному артикулу (ID товара).
  -p, --pages PAGES     Количество страниц каталога для сбора (по умолчанию: 1, ~100 товаров/стр).
  -o, --output OUTPUT   Имя выходного файла (.csv или .json, по умолчанию: wb_products.csv).
  --demo                Демонстрационный режим: генерация выборки офлайн для тестов.
  --proxy PROXY         Прокси-сервер в формате http://user:pass@host:port.
  -v, --verbose         Подробный вывод технического уровня DEBUG.
```

## 📊 Формат экспорта Excel / CSV

Файл выгружается с разделителем `;` и заголовками колонок:
* **Артикул WB:** уникальный числовой идентификатор номенклатуры.
* **Бренд:** официальный производитель / торговая марка.
* **Наименование:** полное название товара.
* **Цена без СПП (₽):** базовая розничная стоимость селлера.
* **Цена с СПП (₽):** финальная стоимость с учётом клиентской скидки WB Кошелька.
* **Скидка (%):** совокупный процент дисконта.
* **Рейтинг:** средняя оценка покупателей (от 1.0 до 5.0).
* **Отзывов (шт):** суммарное число подтвержденных отзывов.
* **Общий остаток (шт):** суммарный остаток на всех складах.
* **Остатки по складам:** детализация остатков (*Коледино: 45, Казань: 12, Электросталь: 28*).
* **Ссылка на карточку:** прямая кликабельная ссылка на товар.
* **Дата сбора:** временная метка UTC.
